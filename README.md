## Overview

Click Craze Affiliated Website is a Next.js site. Visible sections include About page, Blog/Slug page, Blog page, Category/Slug page, Contact page, Deals page, Disclaimer page, Disclosure page.


What is actually in the repository: `.vscode/`, `app/`, `components/`, `hooks/`, `lib/`, `public/`. GitHub reports the primary language as TypeScript.

Published site recorded on the repository: https://click-craze-one.vercel.app

## Getting Started

```bash
git clone https://github.com/Bannysukumar/Click-craze-affiliated-website.git
cd Click-craze-affiliated-website
npm install
npm run dev
```

Scripts defined in package.json:

- `npm run dev` — `next dev --turbo`
- `npm run build` — `next build`
- `npm run start` — `next start`
- `npm run lint` — `next lint`
